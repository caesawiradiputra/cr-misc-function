# Markdown Standards

Common markdown formatting rules shared across documentation skills (`/create-readme`, `/create-confluence-docs`).

## Code Blocks

- Always specify a language identifier (never bare backticks)
- Blank line before and after every code block

## Heading Hierarchy

- H1 -> H2 -> H3 — never skip levels
- One H1 per file (the page title)

## Blank Lines

- Before and after: code blocks, tables, blockquotes, headings, lists
- No double blank lines

## Lists

- Consistent markers: `-` for unordered, `1.` for ordered
- Blank line before first item and after last item
- Keep lists concise and scannable

## Links

- Inline format: `[descriptive text](url)`
- Use forward slashes for relative paths
- Link text must be descriptive (never "click here")

## Line Length

- Under 120 characters

## Tables

- Properly aligned with header separator row
- Keep tables scannable — avoid overly wide columns

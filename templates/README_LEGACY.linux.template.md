## Restoration: Revert to Poetry

If the migration to uv fails or you need to roll back, run these commands from
the project root.

### Step 1: Restore Poetry Configuration

```bash
# Put the original pyproject.toml back
cp legacy/pyproject.poetry.toml ./pyproject.toml

# Put the Poetry lock file back (if one was archived)
cp legacy/poetry.lock . 2>/dev/null || true

# Optional: remove uv-only files
rm -f uv.lock .python-version
```

<!-- IF:conda -->
### Step 2: Restore Conda Environment

Choose one method:

#### Option A: Restore with the same environment name

```bash
conda env create -f legacy/conda-env.yml
```

#### Option B: Restore with a different name

```bash
conda env create -f legacy/conda-env.yml -n my-custom-name
conda activate my-custom-name
```

#### Option C: Restore the exact packages, including Conda packages

```bash
conda create -n restore-env --file legacy/conda-explicit-lock.txt
conda activate restore-env
```

### Step 3: Reinstall Poetry Dependencies

```bash
conda activate <env-name>
pip install poetry
poetry install
```
<!-- ENDIF:conda -->
<!-- IF:no-conda -->
### Step 2: Create a Python Environment for Poetry

```bash
uv python install {PythonVersion}
rm -rf .venv
uv venv --python {PythonVersion}
```

### Step 3: Reinstall Poetry Dependencies

```bash
uv tool install poetry     # Puts `poetry` in ~/.local/bin
poetry env use .venv/bin/python
poetry install
```
<!-- ENDIF:no-conda -->

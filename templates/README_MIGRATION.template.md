## Migration Steps

### Step 1 - Activate Conda Runtime

Choose your Python version (3.11 recommended, 3.9 for legacy support):

```powershell
# Python 3.11 (recommended):
& 'C:\Users\203715\Documents\Repo\cr-misc-function\cr-misc-function\scripts\powershell\conda-py311-init-env.ps1'

# OR Python 3.9:
& 'C:\Users\203715\Documents\Repo\cr-misc-function\cr-misc-function\scripts\powershell\conda-py39-init-env.ps1'
```

**Expected output:**

```text
[OK] Conda py311 activated
Python 3.11.x :: Miniconda
```

### Step 2 - Initialize uv and Create Virtual Environment

From your project root:

```bash
uv init
uv venv
```

This creates:

- `pyproject.toml` (new, uv-compatible)
- `.venv/` (virtual environment with uv)
- `uv.lock` (pinned dependencies)

### Step 4 - Configure VS Code Terminal Profile

Add this to `.vscode/settings.json`:

```json
{
  "python.defaultInterpreterPath": "${workspaceFolder}/{ProjectName}/.venv/Scripts/python.exe",
  "python-envs.workspaceSearchPaths": [
    ".\\**\\.venv",
  ],
  "terminal.integrated.cwd": "${workspaceFolder}/{ProjectName}"
}
```

**Note:** Configure your PowerShell profile to expose manual activation commands (`conda311` / `conda39`) so each terminal can choose the runtime explicitly.
See **[docs/powershell-profile-setup.md](../../docs/powershell-profile-setup.md)** for step-by-step setup instructions.

### Step 5 - Verify Installation

Run these commands in the terminal:

```bash
python --version           # Should show Python 3.11.x or 3.9.x
uv --version              # Should show uv version
uv pip list               # List all installed packages
```

### Step 6 - Update Dockerfile

If your project has a Dockerfile, update it to use uv:

#### Old (Poetry)

```dockerfile
RUN pip install poetry
COPY pyproject.toml poetry.lock ./
RUN poetry install --no-dev
```

#### New (uv)

```dockerfile
# Install uv package manager
RUN pip install uv

# Copy requirements first for better caching
COPY pyproject.toml uv.lock README.md ./

# Install Python dependencies using uv (frozen lock for reproducibility)
RUN uv sync --frozen --no-dev

ENV PATH="/app/.venv/bin:$PATH"

# Copy application code
COPY . .
```

### Step 7 - Clean Up and Commit

```bash
# Remove Poetry artifacts if not already removed:
rm -f poetry.lock

# Commit changes:
git add pyproject.toml uv.lock .vscode/settings.json
git commit -m "chore: migrate from Poetry to uv"
```

## Useful uv Commands

```bash
uv sync              # Install all dependencies (creates/updates .venv)
uv add package-name  # Add a new package
uv add -d pytest     # Add a dev dependency
uv remove package    # Remove a package
uv pip freeze        # Show all installed packages
uv lock              # Update uv.lock file
uv run script.py     # Run a Python script with venv
```

## Troubleshooting

**Issue: `.venv` directory is not recognized by Python extension**

- Ensure `.vscode/settings.json` has correct `python.defaultInterpreterPath`
- Close and reopen VS Code, wait for Python extension to index

**Issue: Commands like `pip`, `pytest` not found in terminal**

- Ensure Conda is activated. Run: `conda activate py311` (or py39)

**Issue: Dependency versions conflict.**

- Manually edit conflicting versions in `pyproject.toml`, then run `uv sync`

**Issue: Need to rollback to Poetry.**

- See `README_LEGACY.md` for restoration instructions

## If something looks wrong

- **Dependency version mismatch:** edit `pyproject.toml` directly, then run `uv sync` to reconcile `uv.lock`.
- **Need to roll back entirely:** see **[README_LEGACY.md](README_LEGACY.md)**.
- **Python interpreter not picked up by your editor:** confirm `.vscode/settings.json` points at `${workspaceFolder}/.venv/Scripts/python.exe` (Windows) and reload the window.
- **Using Conda alongside uv:** activate your Conda environment (`conda activate <env-name>`) before running `uv` commands so uv resolves against the Python interpreter you expect — uv does not manage the base Python interpreter itself, only the project's virtual environment and dependencies.

## Useful uv commands

```bash
uv sync              # Install all dependencies (creates/updates .venv)
uv add package-name  # Add a new package
uv add --dev pkg     # Add a dev dependency
uv remove package    # Remove a package
uv pip list          # Show all installed packages
uv lock              # Update uv.lock file
uv run script.py     # Run a Python script with the project's venv
```

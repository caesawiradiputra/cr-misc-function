## What's in This Archive?

This folder was created automatically before migrating from Poetry + Conda to uv. It contains whichever of the following existed in the project:

- **pyproject.poetry.toml** - Original pyproject.toml (before removal)
- **poetry.lock** (or other `*.lock` files) - Dependency lock file(s) with exact versions that were installed
- **requirements.txt** - Original requirements file, if present
- **conda-env.yml** - Conda environment export (environment name and Python version)
- **conda-explicit-lock.txt** - Explicit list of all Conda packages with versions
- **Dockerfile** - Original Dockerfile if it existed (for reference)

**Important:** These files are for **rollback and reference only**. Do not modify them.

## Restoration: Revert to Poetry + Conda

If the migration to uv fails or you need to roll back, use these commands:

### Step 1: Restore Poetry Configuration

```bash
# Copy the original pyproject.toml back
cp legacy/pyproject.poetry.toml ./pyproject.toml

# Copy the Poetry lock file (if one was backed up)
cp legacy/poetry.lock .
```

### Step 2: Restore Conda Environment

Choose one method based on your needs:

**Option A: Restore with Same Environment Name.**

```bash
# Recreate the environment from the conda export
conda env create -f legacy/conda-env.yml
```

**Option B: Restore with Different Name.**

```bash
# Recreate with a custom environment name
conda env create -f legacy/conda-env.yml -n my-custom-name
conda activate my-custom-name
```

**Option C: Restore Exact Packages (Including Conda Packages).**

```bash
# Use the explicit lock file for full reproducibility
conda update -n base -c defaults conda
conda create -n restore-env --file legacy/conda-explicit-lock.txt
conda activate restore-env
```

### Step 3: Reinstall Poetry Dependencies

```bash
# Activate the Conda environment
conda activate <env-name>

# Install Poetry
pip install poetry

# Install all Poetry dependencies from lock file
poetry install
```
